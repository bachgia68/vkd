MANUAL DEPLOYMENT (Step-by-Step)
================================================================================

STEP 1: SSH to server
-------
ssh user@tasamngoclinh.com


STEP 2: Create backend directory
-------
mkdir -p /opt/strapi-backend
cd /opt/strapi-backend


STEP 3: Copy files from local (run on your machine, not server)
-------
scp mock-strapi-server.js user@tasamngoclinh.com:/opt/strapi-backend/server.js
scp strapi/scripts/setup-collections.js user@tasamngoclinh.com:/opt/strapi-backend/setup.js
scp strapi-admin-dashboard.html user@tasamngoclinh.com:/var/www/tasamngoclinh.com/gate-vkd-control-2026/cms/index.html


STEP 4: Setup systemd service (on server, use sudo)
-------
sudo tee /etc/systemd/system/strapi-backend.service > /dev/null <<'EOF'
[Unit]
Description=TA Strapi Backend API
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/strapi-backend
ExecStart=/usr/bin/node /opt/strapi-backend/server.js
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable strapi-backend
sudo systemctl start strapi-backend


STEP 5: Verify API server running
-------
curl http://127.0.0.1:1337/admin
Expected output: {"status":"ok"}


STEP 6: Populate sample data
-------
cd /opt/strapi-backend
node setup.js
Expected output:
  ✅ Authenticated
  ✅ Created: Sâm Ngọc Linh Premium 6 tuổi
  ✅ Created: Sâm Ngọc Linh 3 tuổi
  ✅ Created: Trà Sâm Ngọc Linh
  ✅ Site header created
  ✅ Site footer created
  ✅ Created: facebook, instagram, youtube, telegram, zalo
  ✅ Setup complete!


STEP 7: Configure Nginx proxy
-------
sudo nano /etc/nginx/sites-available/tasamngoclinh.com

Add these location blocks inside the server block:

# Admin Dashboard
location /gate-vkd-control-2026/cms/ {
    alias /var/www/tasamngoclinh.com/gate-vkd-control-2026/cms/;
    index index.html;
    try_files $uri $uri/ /index.html;
    add_header 'Access-Control-Allow-Origin' '$http_origin' always;
    add_header 'Access-Control-Allow-Methods' 'GET, POST, OPTIONS' always;
}

# API Proxy
location /api/strapi/ {
    proxy_pass http://127.0.0.1:1337/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    add_header 'Access-Control-Allow-Origin' '*' always;
    add_header 'Access-Control-Allow-Methods' 'GET, POST, OPTIONS' always;
}


STEP 8: Test & reload Nginx
-------
sudo nginx -t
Output: nginx: the configuration file /etc/nginx/nginx.conf syntax is ok

sudo systemctl reload nginx

================================================================================
TROUBLESHOOTING
================================================================================

❌ "Connection refused"
   → SSH not configured. Install OpenSSH or use PuTTY
   → Verify SSH key in ~/.ssh/authorized_keys
   → Check firewall allows port 22

❌ "Cannot find file"
   → Run script from D:\TA page\site\ directory
   → Verify all 3 files exist:
     - strapi-admin-dashboard.html
     - mock-strapi-server.js
     - strapi\scripts\setup-collections.js

❌ "Nginx 502 Bad Gateway"
   → Check API server running: sudo systemctl status strapi-backend
   → Verify port 1337: sudo netstat -tuln | grep 1337
   → Check Nginx proxy config: sudo grep proxy_pass /etc/nginx/sites-available/tasamngoclinh.com

❌ "Dashboard shows empty"
   → Run setup script again: node /opt/strapi-backend/setup.js
   → Check API responds: curl http://127.0.0.1:1337/api/products

❌ "CORS errors"
   → Verify Nginx has CORS headers
   → Check browser console (F12)
   → Reload page (Ctrl+Shift+R to clear cache)
