## LAYER 1: CAPCUT AI WEB (Short-Form, 60s Videos)

### How CapCut AI Web Works

**Input:** 1 text prompt  
**Output:** Complete video with visuals + audio + subtitles  
**Time:** 3-5 minutes

**Example Prompt Structure:**
```
[SCENE 1 - 0-15s]
Visual: Images of Sâm Ngọc Linh mountains + harvest
Text Overlay: "MR2 Majonoside-R2"
Audio: Calm background music

[SCENE 2 - 15-30s]
Visual: Product close-ups + QR code scan
Text Overlay: "100% Authentic. Scan to Verify."
Audio: Uplifting tone

[SCENE 3 - 30-50s]
Visual: Customer testimonial clips + smiling faces
Text Overlay: "Trusted by 10,000+ customers"
Audio: Energetic

[SCENE 4 - 50-60s]
Visual: CTA button + shop link
Text Overlay: "Get 15% off today"
Audio: Action-oriented
```

### CapCut AI Web Step-by-Step

```
1. Go to: capcut.com (web version)
2. Click: "Create" → "Auto Captions" or "AI Video" mode
3. Paste: Your detailed prompt (see templates below)
4. AI generates: Full video with:
   ├─ Auto visuals (from prompt description)
   ├─ Auto audio (voiceover in Vietnamese)
   ├─ Auto subtitles (Vietnamese)
   └─ Auto transitions (smooth)
5. Review: 2-3 minutes preview
6. Edit: (Optional) Tweak colors, music, pacing
7. Export: TikTok/Reels format (1:1 or 9:16)
8. Post: Immediately or schedule
```

### Descript Video Production Checklist

```
Step 1: Write script (above format)
Step 2: Record voiceover (do it in Descript directly)
        - Multiple takes OK (AI handles it)
Step 3: Add background music (royalty-free)
Step 4: Upload/select B-roll footage
        - YouTube stock library (free)
        - Your own TA footage
        - Licensed clips
Step 5: Sync visuals to transcript
        - Drag B-roll to timeline
        - Descript auto-syncs to voiceover
Step 6: Add transitions, text overlays, graphics
Step 7: Export to YouTube (1080p, H264)
Step 8: Auto-upload to YouTube channel
Step 9: Schedule post time (optimal: Wed/Thu 2 PM)
```
