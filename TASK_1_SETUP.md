# Task 1: Stable Diffusion WebUI Setup ✅

## Overview
Setup image generation pipeline using **Replicate API** (cloud-based, free tier).
- Stable Diffusion model runs on Replicate (no local GPU needed)
- n8n orchestrates workflow: description → Replicate API → download image → Strapi upload
- 5 sample images generated and stored

## Setup Steps

### 1. Get Replicate API Token (Free)
1. Go to [replicate.com](https://replicate.com)
2. Sign up free account
3. Copy API token from settings
4. Add to `.env`: `REPLICATE_API_TOKEN=<token>`

### 2. Start Docker Containers
```bash
cd "D:\TA page\site"
docker-compose up -d
```

Wait 30s for n8n + Strapi to start:
- n8n: http://localhost:5678
- Strapi: http://localhost:1337

### 3. Configure Strapi
1. Open http://localhost:1337
2. Create admin account (first time only)
3. Create collection: **Products**
   - Fields: `name` (text), `image` (media), `description` (text)
4. Get API token: Settings → API Tokens → Create (Full Access)
5. Add to `.env`: `STRAPI_API_TOKEN=<token>`

### 4. Setup n8n Workflow
1. Open http://localhost:5678
2. Create new workflow
3. Import JSON from: `n8n/workflows/image-gen-replicate.json`
4. Add credentials:
   - **Replicate HTTP Auth**: 
     - Auth type: Header Auth
     - Header: `Authorization: Token <your-replicate-token>`
   - **Strapi HTTP Auth**:
     - Header: `Authorization: Bearer <your-strapi-token>`

### 5. Test Workflow
Run workflow with test prompt:
```
"a luxury ginseng product photo, professional studio lighting, gold background, premium product photography"
```

Expected output:
- Image generated by Replicate SD
- Downloaded to workflow
- Uploaded to Strapi Media
- Image visible in Strapi admin UI

### 6. Generate 5 Sample Images
Run workflow 5 times with prompts:
1. "Sâm Ngọc Linh 20 năm, premium product photography, luxury, white background"
2. "Ginseng root closeup, macro photography, glossy, professional lighting"
3. "Herbal medicine ginseng product, elegant packaging, gold foil, premium"
4. "Vietnamese red ginseng bundle, traditional aesthetic, studio photography"
5. "Sâm Ngọc Linh extract bottle, luxury packaging, professional product photo"

### 7. Verify
- [ ] All 5 images in Strapi Media
- [ ] All images <300KB (if not, run next task: Real-ESRGAN optimization)
- [ ] Image quality acceptable (compare with existing site)

## Troubleshooting

**Replicate API returns 401 error:**
- Check API token in `.env` (copy-paste carefully)
- Verify Replicate account has credits left (free tier: 1000/month)

**n8n can't reach Strapi:**
- Check both containers running: `docker ps`
- Verify `STRAPI_API_TOKEN` in `.env` and n8n credentials match

**Docker port 5678 already in use:**
- Change in `docker-compose.yml`: `"5679:5678"`
